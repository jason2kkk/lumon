# Changelog

All notable changes to Lumon are documented here. Public releases use
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-04

### Added

- Local-first self-hosted runtime with synthetic demo data.
- Evidence-oriented opportunity research across public community sources.
- Apache-2.0 license and contributor/security documentation.
- Reproducible Python and frontend dependency installation.

### Notes

- This is the first public release candidate. External provider keys and
  optional CLI credentials must be configured by each local user.
- The repository does not include private services, credentials, or
  organization-specific deployment configuration.
