# Support

Lumon is a local-first project. Before opening an issue, please check the
README, [the work-principles guide](docs/HOW_IT_WORKS.md), and existing issues.

## Usage questions

Use [GitHub Discussions](https://github.com/jason2kkk/Lumon/discussions) for
setup questions, provider configuration, research methodology, and other
non-sensitive help. Include:

- operating system and Python/Node versions;
- the command you ran and the smallest relevant log excerpt;
- whether the issue reproduces with synthetic demo data;
- the provider or optional CLI involved, without sharing any key or token.

## Bugs and feature requests

Use the issue templates for reproducible bugs and focused feature requests.
Please do not attach private community exports, personal information, full
environment files, or provider responses containing credentials.

## Security

Do not report security vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
